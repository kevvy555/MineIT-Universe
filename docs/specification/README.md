## Ownership and status

Shared game-design principles belong here only when relevant across more than one MineIT game. Authored identity and lore belong to Universe canonical data; per-platform balance, UI, save and implementation belong in game repos. Every module must distinguish **canon**, **user-approved direction**, **proposed**, **open**, **legacy** and **implemented**. Existing older documentation remains in place until reviewed by the upcoming consolidation programme.
