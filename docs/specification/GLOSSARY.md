# Shared MineIT Terminology

**Spec-ID:** UNI-GOV-002 · **Status:** consolidation draft · **Owner:** shared design. Terms are concepts, not invented canonical IDs.

| Term | Meaning | Ownership |
| --- | --- | --- |
| Canonical entity | Persistently authored named thing or type with stable ID | Universe |
| Resource occurrence | Generated local deposit/site instance, abundance and spatial position | Each game/save |
| Raw resource | Naturally occurring material suitable for extraction/harvesting | Universe physical identity; game stock |
| Refined material | Output of a real transformation producing usable manufactured feedstock | Universe identity; game production rules |
| Part | Replaceable manufacturing component or maintenance supply | Universe authored archetype; Desktop exact; Mobile grouped |
| Machinery | Functional equipment installed into an asset | Universe archetype; game installed state |
| Asset | Building, vessel, skimmer, platform, station, rig or related installable/operable thing | Universe authored type; game instance |
| Install/commission | Transfer equipment from loose inventory into an operational asset | Game |
| Industry (legacy Mobile) | Historical abstract production/support capacity using Ore | **Not** shared canon; replacement planned |
| Industry (canonical building) | Workshop/fabrication/maintenance/assembly concept | Universe; future platform use |
| Compatibility | Equipment/environment/technology fitness for use | Shared concept; game rule implementation |
| Deep Reach charter | Year-5326 scenario's commercial claim/contract structure | Universe scenario; Mobile implementation |
| Decision status | Explicitly approved versus suggested or still unresolved rule | Per topic in spec and issue |
| Implemented | Demonstrated production code behaviour | Relevant repo/tests/release |

See [authority rules](DESIGN_AUTHORITY.md) before interpreting older source claims.
