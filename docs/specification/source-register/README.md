# Shared Source Register

Source ledgers classify **existing files without deleting or rewriting them**. A file's route is a candidate ownership mapping, not evidence of full consolidation.

- [Universe documentation and lore inventory](UNIVERSE_SOURCES.md).
- [Desktop documents](DESKTOP_SOURCES.md) — linked to the detailed Desktop register.
- [Android documents](MOBILE_SOURCES.md) — linked to the detailed Android register.
- [Reconciliation and outstanding conflicts](RECONCILIATION_MATRIX.md).

**Statuses:** `Indexed` = path discovered; `Reviewed` = content evaluated; `Migrated` = all relevant rules captured in a new cited spec with conflicts resolved; `Conflict` = mutually incompatible claims; `Historical` = evidence only. A file stays `Indexed` until checked.
