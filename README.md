# MineIT Universe

Canonical shared universe data and directory for MineIT.

This repository owns persistent universe entities and relationships used across MineIT projects.

## Structure

- `data/` — canonical authored JSON source of truth.
- `assets/art/universe/` — universe artwork keyed by stable entity ID.
- `js/` / `css/` — read-only Universe Directory application.
- `docs/` — architecture, publishing and integration documentation.
- `validation/` — consistency and cross-reference validation.

See `AGENTS.md` before changing canonical content.
