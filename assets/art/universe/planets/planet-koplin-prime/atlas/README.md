# Koplin 3 Canonical Atlas Artwork

This directory owns bespoke 1 km × 1 km canonical surface-atlas artwork for `world-atlas-koplin-3`.

Published images use:

```
assets/art/universe/planets/planet-koplin-prime/atlas/<atlas-tile-id>.webp
```

Lossless originals use:

```
assets/art/universe/planets/planet-koplin-prime/atlas/Originals/<atlas-tile-id>.png
```

Generation order, prompts, seam guidance and image state live in `data/world-atlas-tiles.json`.

Do not put reusable Mobile landscape tiles here; those remain under the sibling `landscape/` directory.
