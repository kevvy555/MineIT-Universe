# Koplin 3 landscape tiles

World-specific Mobile grid art for `planet-koplin-prime`.

These tiles belong to `landscape-tileset-koplin-3`. They are not a reusable visual-library series and not a frozen map of Koplin 3.

```text
landscape-tile-koplin-3-*.webp     Directory / game preview
Originals/landscape-tile-koplin-3-*.png   native generation originals
```

The JSON record owns the canonical key. Keep sun direction, camera and palette locked to the tileset style when regenerating any member.
